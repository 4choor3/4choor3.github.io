我的 Python 工具链：把重复的事全部自动化

陈鑫宇2026-09-092026-09-09

我不是计算机科班出身。第一次被 Python 吸引，是因为要整理一份三千行的实验记录表。手工复制粘贴到凌晨两点后，我写下人生第一行 for 循环，第二天十分钟跑完。那一刻我认定了一件事：凡是重复的事，就应该交给脚本。

下面是我这几年慢慢攒下来的工具链，没有高深架构，全是能立刻上手的务实方案。

数据处理：pandas + openpyxl

我日常最多的重复劳动是和 Excel 打交道。pandas 读表、清洗、合并一气呵成，openpyxl 负责那些 pandas 不方便做的”细节活”——改单元格颜色、锁定表头、拆分多个 sheet。

这套组合帮我把每周的报表从两小时压缩到跑一下脚本的功夫。

踩坑心得

  1. 环境先于代码。 八成的”脚本跑不起来”是 Python 版本或依赖不对。我现在一律用 venv/conda 锁环境，README 里写死版本。
  2. 先能跑，再求美。 我大多先用最直白的写法把事办成，确认流程对了再重构。过早抽象反而是负担。
  3. 留日志。 自动化跑在背后，出错你不一定知道。关键步骤 print 或写文件，至少能回头查”它到底干了啥”。

工具链没有终点。每当一件事第二次要我动手，我就问自己：能不能写成脚本？久而久之，省下的不只是时间，更是那种”又得干重复活”的疲惫感。这大概就是我学 Python 最大的收获。
